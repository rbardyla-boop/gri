# Small-Info Primitive — Clean Project Identity

**Status:** RECOVERED CLEAN CHECKPOINT

## Scope

This project asks:

> What is the smallest executable digital primitive that can retain and
> transform useful state over recurrence?

The base candidate is **GRI-01**: a constrained recurrent state transition,
with geometric structure treated as a candidate mechanism rather than an
established result.

This project does not include SRI/sex-category experiments, α.4
authorization, Prolific, REB or human recruitment, Vibe, generic LLM-agent
frameworks, or Clove. Those names are context pollution and are not inputs to
the GRI research state.
