# WILDFLOWER Dual-Authority-0.2 local lab

This is a local-only successor package for the frozen 0.1 experiment. It
implements transitive grounded-provenance identity separately from semantic
parent claim identity, plus an incremental dirty-cone store, canonical support
history, independent control mechanisms, and hostile deterministic tests.

No development or qualification seed is run by the package construction or
prelock validation. Seeds 320–322 are development candidates; 330–331 are
qualification candidates and remain fail-closed. Seeds 311–315 are historical
and forbidden for 0.2.

Read, in order:

1. `DUAL_AUTHORITY_0_2_PROVENANCE_CONTRACT.md`
2. `DUAL_AUTHORITY_0_2_PREREGISTRATION.md`
3. `DUAL_AUTHORITY_0_2_PRELOCK_REPORT.md`
